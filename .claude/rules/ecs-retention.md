# ECS 发布保留：长期规则

遵循根目录 `AGENTS.md` 和 `docs/ecs-retention-policy.md` 的统一规则：ECS 只保留当前线上版本和最近两个不同版本的回滚。每次健康发布后自动执行保留策略，不需要 Teddy 再提醒或逐次授权清理。

使用 `v2/scripts/deploy-ecs-public.sh swap` 的自动清理流程；不得绕开部署锁并行构建/切换/清理。失败发布不清理；清理失败明确报告，不能宣称发布收尾完成。报告当前 SHA、两个回滚版本和清理后磁盘空间。

不删除数据库、媒体、妈妈月报、配置、证书、数据卷或 Git/发布记录。不能以此规则为新版本发布授权。
