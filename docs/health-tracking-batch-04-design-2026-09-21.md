## 1. 页面层级

```
主菜单（固定四项，单排）：首页 / 记忆 / 健康 / 妈妈月报
├─ 首页：一张主照片 · 一句题签 · 近期提醒（生活 / 健康 标记）
│    └─ 健康提醒 → 预约详情 → 就医准备
├─ 健康（首页）
│    ├─ 最近怎么样（资料截止时间 · 依据）
│    ├─ 可能是怎么回事（依据 · 不确定之处）
│    ├─ 现在可以做什么：观察与护理 / 什么情况要尽快就医 / 下次问医生（均可展开依据）
│    ├─ 「记一笔」→ HEALTH-03 工作区（爸妈手记 / 就医 / 已记录）
│    └─ 更多（下一级）：病程时间轴 · 报告与原图 · 就医准备 · 还没归属的记录
├─ 记忆、妈妈月报：沿用现有，本次不改
```

**单排菜单。** 站点底部菜单由三项改为四项，仍是一排。“记一笔”打开 HEALTH-03 已有的全屏工作区，工作区自带三标签并盖住站点菜单，关闭后回健康页，所以任何时刻底部只有一排菜单。桌面用顶部主菜单，底部菜单隐藏。

## 2. 健康首页

1. **先回答“最近怎么样”**：两三句白话概述，标明“资料截至 X 日”，并写明“之后没有记录不代表好了，也不代表没好”。不给评分，不用红绿灯。
2. **医学辅助（核心）**：分三块，每块都有“查看依据”。
   - **可能是怎么回事**：可能的解释 + 支持线索 + 不确定之处 + 医学依据（指南名、检索日期、适用人群）。
   - **观察与护理**：具体到“量几次体温、什么算放心”。
   - **什么情况要尽快就医** / **下次问医生**：危险信号是与个体记录无关的通用信号，资料缺失时不放松；问医生给 3 个最要紧的，完整清单在就医准备。
   - 底部固定一句：“辅助整理，不是诊断，不能代替医生”。
3. **来源三分**：每条依据都标 **家长记录 / 医院资料 / 汇总转述**（对应 HEALTH-01 的来源层级）；医学资料用“医学资料”标注，与个体事实分开。汇总转述只作线索，不作依据。
4. **状态表达**：
   - *资料不足*：直接说“目前还不够说最近怎么样”，收起需要个体依据的分析，只留通用观察方向；“补一句体温、有没有去医院”是可选提示，明写“不补也可以”。
   - *分析过期*：写明“基于 X 日之前的资料，已过 N 天”，提示先看现在的情况或问医生。
5. **记一笔**：首屏右上角一个主按钮，不做红点、不做待办、不催补录。

## 3. 下一级页面

| 页面 | 内容 | 要点 |
|---|---|---|
| 病程时间轴 | 按病程分组的倒序时间线 | 每条标来源类型，医院资料可跳原图；病程起止未知就写未知；没有记录的时间标“没有记录”，不当作健康也不当作生病 |
| 报告与原图 | 按就诊/报告排列的原图 | 显示日期依据和核对状态；摘要与原件不一致以原件为准 |
| 就医准备 | 一页纸：这几天的经过 + 正在用的药（以处方为准，是否服用待家长确认）+ 想问医生的问题 + 已有预约 | 每个问题可回溯出处 |
| 还没归属的记录 | 患者/病程不确定的记录 | **单独呈现**，明写“不并入病程、不影响‘最近怎么样’”；可以以后确认，也可以一直放着 |

## 4. 首页衔接

首页保持“一张主照片、一句题签、一处近期提醒”。在现有“每周提醒”里，每条多一枚 **生活 / 健康** 的文字+图标标记（叶子 / 心电），不新增仪表盘。健康提醒只来自**明确的预约或复查安排**（示例：复查血常规，日期、时间、医院）；不从历史处方生成用药提醒。点健康提醒进入预约详情，再链接到就医准备。

## 5. 与 HEALTH-03 的衔接

- “记一笔”直接复用 HEALTH-03 已验收的三个入口，不重做表单。它是独立会话（`hr_session`）的工作区；健康页读取需要同样的访问保护，实施时须决定同会话或联合会话（见 §6）。
- HEALTH-03 保存的条目（手记 / 就医材料）就是本页“家长记录”和“医院资料”的来源之一；更正、撤销后的有效内容进入本页，撤销的不再出现。
- “已记录”仍是纠错入口；本页时间轴只读，不另设编辑。
