# Nianlife 视觉系统 V1 — 高级家庭成长杂志（稀疏态优先）

> 2026-09-05，Cowork（Orchestrator）写成，Teddy 已定方向：不做多方案比稿，直接落地。
> 性质：阶段性设计文档，服从 `docs/nianlife-product-principles.md`（尤其 §3 原则一/二/三/五/七 与 §4 视觉方向）。冲突时以原则文档为准。
> 参考稿：`docs/design/mockups/home.html`、`about.html`、`month.html`——用线上真实文字和真实照片画的**稀疏态**，是「最少内容时页面长什么样」的样板，不是像素级规格。Code 以本文为规则、以参考稿为手感。

## 0 · 一句话

现在的站是「一本成年人的极简档案，里面放了宝宝照片」。V1 要把它变成「一本从一岁孩子身上长出来的家庭杂志」：**照片是情绪入口，家人的话是主角，日期和数量退到后排。** 温馨来自家人视角，高级来自有选择——不是加粉色，也不是加留白。

三条贯穿的规则：

1. **空态即设计。** 每种布局先按「1 张照片、0 段文字」成立，再谈丰满。任何为了不空而放进去的东西都是违规（原则三、五）。
2. **主阅读层没有数字。** 首页、月页、张年页、记忆索引不出现任何计数（照片数、天数、条数）。计数只允许在折叠的档案层里出现，且只作为 `<small>`。
3. **一页只让一样东西最大。** 首页最大的是封面照，月页最大的是月份名，张年页最大的是肖像。其余一律让位。

## 1 · Tokens（替换 `globals.css` 顶部的 FROZEN FOUNDATION TOKENS）

保留变量名，改值；新增的变量名以 `--nl-` 开头。所有颜色 oklch。

```css
:root {
  /* 纸 */
  --color-bg:       oklch(97.5% 0.014 85);   /* 奶油白，比现在更亮更暖 */
  --color-surface:  oklch(99% 0.008 85);
  --paper-dark:     oklch(93% 0.022 80);     /* 燕麦，用作大块面留白的第二层纸，不是卡片底 */
  /* 墨 */
  --color-text:     oklch(28% 0.03 45);      /* 深巧克力，不是冷黑 */
  --color-primary:  oklch(28% 0.03 45);
  --color-muted:    oklch(50% 0.03 50);
  /* 点睛 */
  --color-accent:   oklch(58% 0.11 45);      /* 低饱和杏橙（文字用，对比度≥4.5:1） */
  --nl-apricot:     oklch(74% 0.10 55);      /* 杏橙印章/刻度用，只做线和小面，不做文字 */
  --nl-sage:        oklch(60% 0.05 145);     /* 鼠尾草绿：称谓点、成长刻度、第二种标记 */
  --color-secondary: var(--nl-sage);
  /* 线 */
  --color-border:   oklch(90% 0.018 78);     /* 更淡；且 V1 之后整页最多出现 2 条通栏横线 */
  /* 字 */
  --font-heading: "Songti SC", "STSong", "Noto Serif CJK SC", "Source Han Serif SC", "Songti TC", Georgia, serif;
  --font-body:    "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, sans-serif;
  /* 圆角：只有照片允许 2px，其余一律 0 */
  --radius-sm: 2px; --radius-md: 0; --radius-lg: 0; --radius-xl: 0;
  /* 节奏 */
  --nl-gap-day:   clamp(56px, 9vw, 96px);    /* 月页两天之间 */
  --nl-gap-block: clamp(32px, 6vw, 56px);    /* 一天之内文字与照片之间 */
  --nl-bleed:     16px;                      /* 手机左右安全边距；照片可以突破它到 0 */
  --ease-out: cubic-bezier(.25, 1, .5, 1);
  --nl-dur: 600ms;
}
```

**字体预算：0 KB。** 不引入任何 webfont（也否决手写体，Teddy 已定）。中文衬线走系统 Songti / Noto Serif，无则退到 serif；这是有意为之，安卓上退化成黑体也成立。`body::before` 那层纸纹保留，opacity 降到 `.10`。

## 2 · 字阶（只用这六档，不新造）

| 名 | 用途 | 字体 | 尺寸 | 备注 |
|---|---|---|---|---|
| display | 月份名（月页）、「张年」（张年页） | serif 500 | `clamp(2.6rem, 9vw, 5.2rem)` | letter-spacing -.03em，line-height 1.0。**首页不再用 display 级标题**（见 §5.1） |
| title | 记忆标题、首页封面那一句 | serif 600 | `clamp(1.5rem, 5.2vw, 2.2rem)` | line-height 1.25 |
| quote | 家人原话 | serif 500 | `clamp(1.25rem, 4.2vw, 1.6rem)` | line-height 1.5；带「」；后跟称谓行 |
| body | 正文 | sans 400 | `1rem` / 1.75 | 最大 34ch |
| dateline | 日期标记、年龄 | sans 500 | `.78rem`，letter-spacing .06em | `--color-muted`；数字 tabular |
| mark | 栏目小字（如「这个月记下来的」） | sans 700 | `.72rem`，letter-spacing .08em | `--color-accent`。**每页最多 3 个** |

现有 `.section-mark` 就是 mark；`.serif` 类保留。所有 `h1/h2` 的 `clamp(…, 14vw, 9rem)` 级巨字全部下调到 display 或 title。

## 3 · 品牌小件（统一的宝宝专属细节，全站只有这四个）

不用任何现成儿童图标；四个小件全部是几何 + 文字，内联 SVG，颜色只用 `--nl-apricot` / `--nl-sage` / `--color-muted`。

**3.1 年龄印章 `AgeStamp`** — 一枚 1px 描边的椭圆（约 96×64），杏橙描边，内文两行：serif「1 岁 8 个月」+ dateline「2026 年 9 月」。整体旋转 -4°。**每页只盖一枚**：首页封面下、月页刊头、张年页肖像下。它是原则二「生命时钟」的视觉体，替代散落各处的「当时 1 岁 X 个月」。

**3.2 日期标记 `DayMark`** — 一段 14px 长、2px 粗的杏橙短线 + dateline「9 月 3 日」。它取代月页里每天上方的横线：**月页正文里不再有通栏 `<hr>` / border-bottom**，日子之间靠 `--nl-gap-day` 的空和这枚短线区分。跨月龄边界的那天，在 DayMark 右侧多印一次年龄（沿用 T16 V1 的规则）。

**3.3 称谓点 `Speaker`** — 6px 鼠尾草绿圆点 + sans 500「妈妈」「奶奶」「雪姨」「老师」。只出现在 quote 下方一行：`● 妈妈 · 8 月 28 日`。称谓来自 registry，解析不到就整条 quote 不出（T7 硬边界）。

**3.4 成长刻度 `GrowthRuler`** — `/memory` 索引页年份导航的替代：一条竖向细线，每个月一个刻度，刻度旁 dateline 印月龄（「1 岁 6 个月」），有记忆的月刻度用杏橙加粗，没有的用 `--color-border`。**只在 /memory 出现**，是全站唯一允许「看到全年」的地方。V1 可以先用简化版（等距刻度，不按天数比例）。

## 4 · 照片布局（三种，按数量自动选）

照片永远保持原比例（沿用 `Photo` 组件），圆角 2px，不加阴影不加边框。

| 数量 | 布局 | 规则 |
|---|---|---|
| 1 | **bleed** | 手机上左右出血到 0 边距（`margin-inline: calc(-1 * var(--nl-bleed))`），桌面上在阅读栏内满宽。高度上限 `80vh`，竖图用 `object-fit: cover` 裁上下不裁左右 |
| 2 | **duo** | 两栏 3:2 不等宽，底对齐，间距 6px；主图在左 |
| ≥3 | **cluster** | 一大 + 两小竖排（大图占 2/3 宽），只展示前 3 张，其余进折叠档案 |

**节奏规则（月页）**：连续的两天若都有单张 bleed 图，第二天的图改为 **inset**（宽 86%，靠右），第三天再回到 bleed。这就是「大小交错」，不需要更多变体。
**首页最近一组**：固定 cluster，来源是最近 3 条「有绑定照片的已发布记忆」，每张点进 `/events/[id]`。

## 5 · 页面

### 5.1 首页 = 封面

自上而下，**每一块都是可选的，没有就不渲染，也不改变其余块的样式**：

1. **封面照**（bleed，`priority`）。来源：`home-view` 现有 cover 规则里最近一条带 hero 的记忆。没有 hero 时封面变成纯排版：AgeStamp 放大到 1.4 倍居中 + 那一句标题——**这就是稀疏态封面，参考稿 `home.html` 画的就是它**。
2. **AgeStamp**：「1 岁 8 个月 · 2026 年 9 月」。
3. **那一句**（title 级）：cover 记忆的 `title`。它是首页唯一的大字。**删除现在的巨型「最近怎么样，张年。」刊头**——brand 已经写着「张年的人生档案」，封面自己会说话。
4. **家人说**（quote + Speaker）：从 cover 记忆 `story` 里用确定性规则抽第一句带称谓的原话——正则 `(妈妈|爸爸|奶奶|雪姨|老师)(说|转述)?[：:]?「([^」]{2,40})」`，取第一处。抽不到就不渲染这块。**不允许 AI 生成、不允许无称谓**。
5. **最近长大的一点**：现有 `change`，样式改为 quote 级一句 + dateline；只显示一个。
6. **最近的一组**（cluster）：见 §4。
7. **本月**：像一本月刊的封面——燕麦色底一块（这是全站唯一允许的色块），内含 dateline「2026 年 9 月」、月度回顾第一句（serif，若无回顾则用该月第一条记忆标题）、一张该月照片（inset）。整块可点，去月页。没有任何内容的月不渲染。
8. 首页**没有**「上一段记下来的生活」的重复块——cover 已经是它。

### 5.2 月页 = 一期杂志

1. 刊头：back-link 小字；**display 级月份名**「2026 年 8 月」；AgeStamp；月度回顾（`summary`）作 standfirst，serif quote 级、行高 1.6、最大 30ch。无回顾时刊头只剩月份 + 印章，**不放「这个月记下 N 天」**（T21 的第二步在此落地：那行整个取消）。
2. 正文「这个月记下来的」：每天 = DayMark + 记忆标题（title）+ 正文（body）+ 照片（§4 布局）。**日子之间无横线**。
3. 「这个月的日子」（chronicle）合并进正文，不再是第二个列表；照片日但无文字的按原则不出现在正文（T16 V3 不变）。
4. 折叠档案：`<summary>` 只写「整月照片档案」，**去掉「N 张」**；打开后按天 DayMark + 网格，这里才允许密。
5. 「其他月份」页脚保留，改为 dateline 级一行。
6. **稀疏月**（例如只有 3 天文字、0 张照片）：刊头 + 三段 DayMark 文字。参考稿 `month.html` 下半部分演示了这一态。它必须看起来像「这个月很安静」，不像「数据没导」。

### 5.3 张年页 = 全站最有宝宝感的一页（V1 只做骨架）

1. **肖像**（bleed，高度上限 80vh）。选择规则改为：取**最近一条已发布记忆所绑定的 hero**，且该 media 的来源身份必须是夸克 `family_photo` 背书；乳儿班 / 微信来源即使 trusted 也**不得**作肖像（今天线上肖像是乳儿班 9/3 的香蕉和牛奶——这是这条规则的来源）。无符合者则复用首页封面照；再无则不放图，页面从印章开始。
2. **AgeStamp 放大 1.4 倍**，其下 dateline 一行「2025 年 1 月 3 日出生」。
3. **家人最近说**：最近 30 天内已发布记忆里按 §5.1 正则抽到的原话，最多 3 条，quote + Speaker，每条可点去记忆页。抽不到就不渲染。
4. **最近长大的一点**：同首页 `change`。
5. **最近记下来的**：现有 `currentNotes`，改为 DayMark + title 的紧凑列表，去掉 `<dl>` 的定义列表样式。
6. 「更早的时候」「更深的资料」保持折叠。
7. **不渲染**任何空格子。「最近爱说的话 / 学会的动作 / 吃睡习惯」属于批次 C 的内容管线，V1 不留占位。

### 5.4 记忆索引 `/memory`

刊头下调为 display 级「记忆」+ 一句副题；年份区块用 GrowthRuler；月份行 = serif 月份 + dateline 月龄 + **该月第一条记忆标题**（替换掉现在的「N 段记忆 / N 张照片」计数）。展开的月份沿用 §4 cluster。

## 6 · 动效（三种，其余一律不做）

- **reveal**：进入视口时 opacity 0→1 + translateY 8px→0，`var(--nl-dur)` `--ease-out`，只做一次。用于每个 section。
- **drift**：封面照与肖像加载后 `scale(1.02)→scale(1)` 12s 线性，一次。
- **翻页**：月页间的导航用 View Transitions（若浏览器支持）做 220ms 交叉淡入；不支持就无动效。
- `@media (prefers-reduced-motion: reduce)` 下三种全部关闭。**没有**蹦跳、闪烁、轮播、hover 位移（现有 `.text-link:hover { transform: translateX(4px) }` 删除）。

## 7 · 明确不做（Anti-patterns）

彩虹、小熊、云朵、脚印图标、气球；糖果色；圆角卡片阵列；满屏横线；handwriting webfont；任何 AI 生成的「人味句子」；封面用无背书照片；为了填满放占位；「暂无」「0 张」「还没有」类文案；在首页解释系统在做什么。

## 8 · 验收（Cowork 会做的，按页面说）

1. 打开首页不点任何东西：第一屏 ≥ 60% 是照片（有 hero 时）；没有一个数字、没有一条通栏横线、没有两块同尺寸的卡片；能说出「张年现在 1 岁 8 个月，最近……」。
2. `/memory/2026/08` 与一个稀疏月（如 `/memory/2025/03`）都成立：无横线分隔、无计数、无「暂无」；稀疏月读起来像安静而不是故障。
3. `/about` 肖像是张年本人，来源是夸克背书；「家人最近说」每条有称谓且能点回原记忆；页面上没有空格子。
4. 随机截三屏：无工程名词、无计数（原则三）；重要记忆与普通一天一眼可分（原则五）。
5. 每一句展示出来的文字都能在数据库里找到出处（Cowork 抽读 5 条）。
6. 手机（375px）上正文不被裁切、不横向滚动（8 月页今天有这个 bug）。
7. `prefers-reduced-motion` 打开时页面无任何动画。
8. 全站新增字体请求 = 0。
