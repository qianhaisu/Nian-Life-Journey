### 照片与题签

1. 删除 `.home-figure` 的 420/444px 桌面上限及原等分布局。右侧图像区约占版心 2/3，1440 视口下目标宽约 800px；不能只放大外框、内部仍塞一张 444px 的小图。
2. 主视觉高度初始取约 560–640px，实际由照片比例和视口决定。横幅、竖幅均检查原片后取景：不得拉伸、不得切掉脸/手/脚及关键动作。竖片允许有意留白，不以过度裁切强凑横幅。最大区域是照片区域，强调色和提醒不能与其争抢注意。
3. 删除首页正文摘录渲染，不能只是 CSS 隐藏。已有真实故事标题就是题签，最多两行；不再附一段摘要，也不新增 AI 口号。标题过长时与数据轨确认现有可用短题签；没有可靠短题签则保留标题并使用两行显示限制，完整标题可访问，不能自行改写事实。
4. 删除独立的大号“最近怎么样，张年”问候区，将今天/当前年龄收为左栏小字；避免两个大标题竞争。主故事题签是唯一主要文字标题，保留正确标题语义。
5. 本轮首页不再露出第二条“近况”入口，降低阅读负担；对应记录和内页保持可达，数据契约可以保留 recentFact 供其他用途。
6. 逐篇 0–2 段强调配置继续使用。未配置不着色，不恢复关键词正则。不为了两行把字号缩小到难以阅读。
7. 照片点击原比例查看、换图带动题签/日期/年龄/链接、阅读入口进入真实事件，这些原功能必须保留。

### 轻便签

1. 桌面放左栏下方，与题签同一左对齐线；最大宽度 300px。移除通栏背景、大圆角条、阴影和右侧独立“查看详情/去核实”按钮。
2. 默认一条、确有需要最多两条，纯文字呈现“事情 + 时间/必要状态”，一条一行或自然换行；使用低调的 `这几天` 标签。字号仍可读，不靠缩成极小字制造“轻”。
3. 整条可展开，保留键盘操作、明显但克制的焦点/展开提示，交互命中区域至少 44px。详细来源、原始日期与状态放展开层；其余有效事项只占一个轻量展开入口。过期事项不重新塞回近期提醒。
4. 无有效提醒时整块隐藏；重要事项仍可达，不能为了尺寸删除、改状态或隐藏关键信息。展开后可以自然增高，不把详情强塞进固定高度。
5. 改 DOM 时同步调整 HabitShownReporter 的观察对象：只观察默认事项，元素实际可见且页面前台才上报，离开视口要移除待报资格。不能因移动便签而让旧 CSS selector 失效，也不能把折叠项算入默认展示。
