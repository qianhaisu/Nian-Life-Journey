## 一、审核指出的四项，逐项结果

### 1. 发生时间与复合事实

- **删除了 R4 的「即时」规则**：它拿 AI 撰写的 basis 里出现同日时刻来自证，再无条件把发生时间设为发送时刻。
  这正是 R2/R3 已被指出的错误，我又做了一遍。
- 现在发生时间**只由原文**经生成器与验证器共用的规则（`f_rules`）推出：原文明示时刻 → 该时刻（精度到分）；
  原文含「刚…」类近似标记 → 发送时刻、精度标为近似；否则保持未知。
  审核点名的那条「原文明写某个时刻却被记成发送时刻」已修正。
- 有发生时间的事实从 R4 的 44 条**收窄**为 18 条（13 条原文明示的回溯、2 条明示时刻、2 条近似、1 条区间）。
  被收掉的 26 条是靠 basis 自证的裸读数——它们**本就不该有**发生时间，不是「未知变已知」的回退。
- **同一规则扫过全表**：问句承载邻居完成事实的共 **12 处**（含审核点名的 3 处，07-12 那组保留），
  另 1 处只降级。全部拆分：问句自身仍记问句，答复绑到真正说出它的那条消息，问句列入支持链。
  跨会话的关联另存为「相关背景」，**不冒充支持链**。
- 显式适配、类型与会话恢复的成果保留；R3 遗留的最后一条类型缺失也已显式定型。

### 2. 病程计数、就诊分类、汇总稿连接

- 病程**视图 10 条，去重后 9 组**：按表里已确认的「同一事件的两个视图」关系归并，
  待判关系（如三次呼吸道就诊是否同一长病程）**继续保留、不强并**。
- 就诊分列：**13 次已发生就诊**、1 条预约（未确认是否就诊）、1 条仅检查记录（与某次就诊同日）、
  1 条非本人记录（隔离）。预约与检查可挂靠病程，**不计入就诊次数**。
- 汇总稿连接改用**真实 schema**（`linked.*` / `record_id`），此前全部为空；
  一行同时连着六次就诊的（如出生日期互证）说的是全档案的事，不往某段病程里挂。
  转述层已回答的内容（雾化做过后停、住院手续经过）回到病程里，**并保留边界**：次数未知、原始医嘱未核对。
- **底层文字**已改（不是只在文档里加禁词）：无原件的一段不再写成「没有就诊、没有处方、没有化验」，
  七月那一段不再称「实际给药证据」，九月一段的执行情况改为转述层表述。
- 临床类微信事实的去向：188 条已挂靠病程，168 条**逐条写明未挂靠原因**（92 条非呼吸道话题、
  76 条落在所有病程的证据窗口之外），**不构成新病程主张**。

### 3. 验证器与仓库新增函数

**验证器每一项都改成「用独立来源重新推一遍再比」，不再比存下来的东西**：

| 检查 | 独立审核指出的盲区 | 现在怎么验 |
|---|---|---|
| V3 | 只管本次召回缺口 | 三路来源（召回缺口 / R3 逐条 / R2 已审）+ 拆分补记，各自集合守恒 |
| V6 | 比存下来的哈希，不比展示摘录 | 回原件重读：摘录、哈希、发送人、时间；**每个支持引用**必须真实存在且同会话 |
| V7 | 比旧 R2 原文，不比当前内容 | 由继承来源 + 登记表**重新推导全部事实，整条全内容比对** |
| V8 | 只查规范层、只提数字 | 规范层与观察层各自按纸面期望比**数值 + 单位 + 频次**，且两层互相一致 |
| V2 / V5 | link 只要非空；不查就诊引用 | link 必须指向真实条目；规范层与观察层的就诊引用必须存在 |
| V9 | time_note 非空即可 | 由原文按共用规则重推，或必须在显式期望表里 |

| V19（新） | 私有链没调用仓库函数 | 私有验证**真的调用仓库的 `verifyCitations`** 核对 JSON 会话引用（545 条通过；Markdown 会话无消息级 ID，216 条由 V6 核对） |

**反例 26 → 50 条**，每条都断言检查器返回 False，且**包含审核点名的十类**：
删一条 R2 已纳入事实、当前 basis 改成非空错误事件、展示摘录改成非空错误正文、只改观察层药量、
规范层单位换掉数值保留、支持引用指向不存在的消息、sup 的 link 指向不存在的条目、
规范事实的就诊引用指向不存在的记录、显式时间改成任意过去日期、预约改成就诊。

**仓库新增函数的缺陷成立，已修**：`buildMessageIndex` 原先用 `Map.set` 覆盖，
同身份不同内容时**输入顺序决定保留哪一版**，且引用碰巧指向最后一版就通过。现在：
- 内容互异的版本**全部保留**，与输入顺序无关，内容完全相同的重复只留一份；
- 有歧义又没带哈希 → 报 `ambiguous`，**不挑一版说通过**；带了哈希则可消歧，一版也不命中算内容不符；
- 没带哈希只核了定位 → `ok` 但 `verified` 为 false，并列入 `unchecked`，**不冒充正文已核**。
合成测试 32 → **37**（5 个新用例：顺序无关、重复折叠、歧义、消歧、未核）。

### 4. 医学终态

- **最近一次体重记载改为 2026-09-10 的医院病历页眉**（此前遗漏，且我上一轮还写了「06-15 之后没有任何测量」——
  这是同一类错误第三次出现：我只搜了结构化字段，没扫页眉）。现在页眉体重由 OCR 文本**独立扫描**，
  验证器用同一规则再扫一遍，序列里缺任何一条都会失败。

- **求助边界恢复并分档**（依据 NICE NG143 §1.3、1.6、1.7，已读原文）：

  夜间查看不再写死一次。
- 家庭问题分层：**当前观察 5 条**（呼吸费力、精神/饮水/尿量、咳嗽鼻涕发热、用药状态、体重身高）

- 四份文件由冻结的终态**整份重写**，不回用 R2 旧内容当终态。
