## 问题与修正（`v2/app/health/record/record-app.tsx`）

后一次 401 只能证明**这次重试没有执行**，不能否定此前那次可能已提交。修正前，NoteForm/VisitForm/Sheet 的 401 分支无条件清掉冻结的请求并提示“这次没有保存”，随后改正文会以同一 ID 提交异文（409），更正则丢失原请求 ID。

现在每次提交先判断“此前是否已有结果未知的冻结请求”：
- **是**：401 后保留原请求、ID、图片和冻结状态，表单继续锁定，提示改为“这次重试没有执行；上一次的结果仍然不确定（可能已经保存/生效）”，仍提供“放弃这次，作为新记录 / 放弃这次操作”的明确出口。同一位家长重新登录后（工作区草稿常驻），点重试即原样重放，服务端按 ID 幂等返回已保存的那条。
- **否（新请求首次 401）**：行为不变，仍解冻并保留草稿，可编辑后重试。
- 新建手记、新建就医、更正、撤销、恢复、“用我的草稿”共用同一原则（后三者经 `Sheet.send`）。
