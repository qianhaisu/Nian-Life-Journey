# 媒体查看体验修复

照片查看器原先渲染在带 transform 的页面动画容器内，fixed 定位受祖先约束，导致弹层只覆盖局部、关闭键离开可视区。现通过 portal 挂到 body，并使用原生 modal dialog 顶层；照片区域按剩余视口高度收缩，以 contain 完整显示，关闭和翻页控制保留独立空间。背景不可交互，关闭恢复焦点及阅读位置。

视频首次播放前移除原生 controls，仅显示一个居中的自定义播放按钮。首次 play 事件后启用原生控制条并移除自定义按钮，暂停后也不重新叠加。既有点击播放、全屏请求与拒绝回退逻辑保留。

验证：
- 类型检查、Lint、生产构建通过。构建使用独立产物目录，未替换其他任务的构建。
- 全量测试 1359 项：1348 通过、11 跳过、0 失败。
- `node test/media-overlay.browser.mjs`：实际共用组件与全站 CSS，在具有 transform/overflow 的滚动容器中复现环境；使用合成照片和浏览器生成的视频，不访问家庭数据。
- Chromium 390×664、1280×800：弹层覆盖视口、完整比例、关闭键可见、翻页、双击放大后关闭、Escape、浏览器返回、阅读位置恢复通过。
- 单个初始播放键、真实视频播放与全屏、退出并暂停后原生控制且没有叠加按钮通过。
- 未实测 iOS/微信内置浏览器；不能将 Chromium 验证视为 iOS 真机通过。
