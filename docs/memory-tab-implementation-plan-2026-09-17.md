## 一、要达到的阅读体验

**记忆以日子和成长为主线，照片为故事服务。**

| 层级 | 要回答的问题 | 展示内容 |
| --- | --- | --- |
| 记忆主页 `/memory` | 这个月最值得记住什么？ | 能看清小年的代表照片、月份/真实年龄、当月独有的一句话 |
| 月度主页 | 这个月小年有哪些变化，每一天发生了什么？ | 一段月度总结；按日期连续排列的「每日故事或照片描述 + 当天精选照片」 |
| Event 详情 | 这一天的故事是什么，当时留下了什么？ | 完整故事、故事配图与当天精选补图、一个统一展开的原始资料区 |

明确去掉月页顶部和底部的整月相册入口/区块；取消「故事配图 + 当天照片 + 当天相册」的三重堆叠。月页每天只留一组精选媒体、一个展开按钮。展开后仍是有价值的精选内容，不把未选中的连拍重新倒回来。

### 建议作为九月样板的编辑标准

- **月份封面**：先看人物、表情、动作和构图，再看成长节点和季节特点。优先一张主图；当生日与玩雪等两件事共同代表该月时，可设计两张互补照片的组合，不要求每月都凑两张，不新增自动轮播。手机与桌面分别验证裁切。
- **封面一句话**：写该月与其他月最不同的事，不能用任意一条故事标题或月总结第一句充数。月份名换掉仍适用于任何月份的句子应退回。
- **月度总结**：通常一至两段，参考 100–180 字，但不靠凑字数达标。概括成长变化及这个月的生活特点，用少量具体事实支撑；不逐天复述，不堆原话，不写成五条快照。九月未结束时只概括已发生的部分。
- **日故事**：同一天默认一个主标题、一篇连贯短故事。重复的短记录合并，不把无关片段编成因果关系；仍可在同一篇里分自然段。原始事件及来源保留。
- **只有照片的日子**：放回实际日期位置，写简短、可核验的画面描述；无素材的日期不造故事，不补虚假连续性。
- **选片**：按「完全重复 → 视觉近似 → 同场景同动作 → 是否增加记忆价值」四层筛选。相同衣服或地点本身不构成重复；不同表情、动作转折和重要人物互动可以分别保留。默认展示 1–3 张为样稿起点，不凑数量。
- **Event 补图**：当天精选补图默认全部展开；与故事已绑定的图片合并去重。仅因同日而补入的照片放在「这一天的照片」中，不冒充故事现场证据。
