# Nianlife 访问统计（本地管理后台）

## 架构说明

访问统计严格遵守隐私与安全规则，区分**线上日志采集**与**本地统计后台**：
- **线上日志采集**：由公网入口 Caddy 直接记录访问日志至容器具名卷 `/data/log/access.log`（保留 50 个轮转归档文件，最长保存 90 天）。Caddy 直连网卡识别真实客户端 IP，防伪造转发头；抹除 Cookie 与 Authorization 等鉴权头；不输出请求正文；保留完整 User-Agent。
- **本地统计后台**：**只在本地 Windows 运行**，通过 `127.0.0.1:4000` 访问。不部署至公网域名，不向公网暴露任何统计接口或 IP 明细。
- **数据同步**：本地通过安全 SSH 直连 ECS 读取并增量拉取日志，凭据读取用户主目录私钥（`C:\Users\teddy\.ssh\nianlife-prod-ecs.pem`），不在仓库中保存凭据。日志本地持久化存储于 `v2/.data/stats.db`（SQLite WAL 模式），已被 `.gitignore` 排除，避免向 Git 泄露。

---

## 本地启动与访问方法

在项目 `v2` 目录或根目录运行：

```bash
# 方式一：npm 脚本（在 v2 目录下）
cd v2
npm run stats

# 方式二：Python 直接启动（端口默认 4000，可自定义）
python v2/scripts/stats/server.py 4000
```

打开浏览器访问：
👉 **http://127.0.0.1:4000**

## 数据增量同步

可在网页后台右上角点击 **「🔄 增量同步线上数据」** 按钮，或者在命令行执行：

```bash
# 在 v2 目录下
npm run stats:sync

# 或直接运行 Python 脚本
python -m v2.scripts.stats.sync
```

- **压缩归档日志**：首次拉取后记录在本地 `sync_state` 表中，后续不再重复下载。
- **当前活跃日志**：仅增量拉取自上次同步之后产生的最新日志行，秒级完成同步。
- **去重机制**：每条请求以时间戳、IP、Method、URI、Status 及 UA 计算确定性 SHA-256 哈希，完全幂等去重。
- **IP 归属地自动解析**：新发现的 IP 自动通过离线与批量查询服务解析省市、运营商并永久缓存在本地 SQLite `ip_geo` 表中。

## 统计口径说明

1. **页面浏览量 (PV)**：
   - 必须是成功响应（状态码 200 / 304 / 206）的 GET/HEAD 请求。
   - **严格排除**：静态资源（`.js`, `.css`, `.woff2`, `.png`, `.jpg`, `.mp4` 等）、Next.js 预取请求（带 `Next-Router-Prefetch: 1` 或 `Purpose: prefetch` 头）、健康检查探针（`/api/health`）、后台 API 请求（`/api/...`）以及漏洞扫描尝试（`.env`, `.php` 等）。
   - **单页应用支持**：兼容客户端路由切换（SPA Navigation）。Next.js 客户端跳转请求（`Rsc: 1` 且非 Prefetch）会被识别为真实浏览，并提取其真实目标页面路径。
2. **独立访问 IP (UV)**：
   - 基于公网来源 IP 去重。
   - **关键提示**：**IP 数 ≠ 人数 ≠ 设备数**。同一家庭/公司 Wi-Fi 共享一个公网 IP；移动网络基站切换导致同一手机 IP 变化；同一设备可能使用多个浏览器。
3. **网络爬虫与安全扫描**：
   - 自动识别已知搜索引擎爬虫、自动化探测工具、扫描器与无头浏览器，单独归类统计，不计入正常人类访客 PV/UV。
