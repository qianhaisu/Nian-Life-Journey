# Nianlife 全站改善方案

日期：2026-10-12。状态：**等待 Teddy 审批，尚未实施**。依据[全站验收报告](nianlife-impeccable-audit-2026-10-12.md)。

建议按三批实施，保留现有纸色、字体、五项主导航、旅行地图、月报特色和原始事实。先处理访问与操作，再改善可信阅读和定位，最后收敛视觉与失败恢复。每批形成可独立检查的提交；生产部署仍需人工批准，发布时记录 SHA、回滚版本和清理结果。

## 第一批 访问和操作

这批先让家人能可靠打开、阅读、退出，让内部候选保持在服务端边界内。

| 工作 | 具体变化 | 完成标准 |
|---|---|---|
| 内部候选关闸 I04 | `/inbox` 默认关闭；若审批包含认证范围，再实现服务端管理员认证；保留 capture / preview gate | 匿名读取不能取得内部候选；新增授权路径在 fixture 中验证；不靠隐藏导航实现 |
| 健康附件模态 I01 | 复用成熟 Dialog，统一初始焦点、背景隔离、Tab 循环、Esc / 返回、触发处归还 | 桌面与手机模拟下焦点不进入背景；Esc、按钮、浏览器返回只关闭当前层；关闭后滚动与触发焦点恢复 |
| 健康记录详情风险 | 对待提交 Sheet 补 loading / error 关闭入口与相同焦点契约 | 所有状态可退出；草稿、幂等、冲突和历史更正回归保持有效；真实生产写入不用于测试 |
| 照片放大 I05 | 加“放大 / 还原”按钮与状态，支持键盘，保留照片完整比例 | 指针与键盘均可放大 / 还原；放大后能移动查看；翻页、Esc、浏览器返回和焦点恢复通过 |
| 功能字对比 I02 | 月报绿色 / 蓝色字、录入提示、空态字使用校验后的深字色 token | 普通功能字实测至少 4.5:1，大字至少 3:1；包括真正的背景合成，保留原面色与维度含义 |

健康既有公开读取决定不在这批自动翻转。建议同时收紧健康写入和原件访问的身份验证，但这属于明确的访问策略变更；只有审批包含该范围才执行。自报“妈妈 / 爸爸”和同源 Origin 不作为身份认证。若需要设置新凭据，凭据进入私有运行配置，不能进入仓库或验收截图。

建议 skill 顺序：`/impeccable harden` → `/impeccable colorize` → `/impeccable audit`。

## 第二批 可信阅读和定位

这批让读者能认清资料的时间与性质，并在长页里找到下一步。

| 工作 | 具体变化 | 完成标准 |
|---|---|---|
| 健康统计语义 I03 | 指标表达记录 / 估算性质；数字旁常驻短限定；完整方法保留在说明内 | 不会把疑似 / 补算区间表述成确诊事实；数据和历史记录不变；日期、截止时间、估算说明可同时看见 |
| 健康手机入口 I06 | 保持比例轴，扩展互不冲突的命中区；密集记录分组；增加同日期记录列表 | 主要操作目标按 44px 设计；小轴目标逐项核对 24px / 间距 / 等价入口要求；合成触摸点按、横滑、取消手势后恢复通过 |
| 历史日期身份 I08 | 历史月报用“这个月 / 当时”，相关“当前”限定移到区块开头；首页明确资料月份 | 首页、月报、健康的“事件时间 / 资料截至 / 整理时间”不会混淆；不编造最近动态 |
| 月份与月报结构 I07 | 周 H2、日 H3；月报去嵌套 main，增加 3–4 组就近目录；保留现有周链接和返回锚点 | 每页仅一个 main；skip link 正常；标题导航可按周 / 日移动；返回原日和周锚点正常，现有日期链接不丢失 |
| 地图入口与键盘 I10 | 给地图 / 旅程文字捷径；完善 Tab 键盘模式或改为真实按钮组 | 指针、Tab / Enter、方向键约定与 ARIA 语义一致；地图选择与对应旅程关系清楚 |
| 大字与祖辈阅读 I11 | 功能说明优先 14–16px；数值 / 单位可换行；三列可降为单列；底栏高度适应文字 | 320 / 390 / 768 / 1440px 可读；200% 文字模拟无数字 / 单位重叠、无导航文字裁切；真实浏览器缩放补验 |

建议 skill 顺序：`/impeccable clarify` → `/impeccable adapt` → `/impeccable typeset` → `/impeccable layout` → `/impeccable distill`。

## 第三批 视觉一致性和媒体恢复

这批集中处理显眼的空态、媒体失败，以及少量实现漂移，不扩大成整站重设计。

| 工作 | 具体变化 | 完成标准 |
|---|---|---|
| 无图旅程 I09 | 已授权封面不存在时使用文字明信片或收起照片区 | 最新旅程不留下整块空照片框；不生成虚构照片，不改变旅程事实；卡片仍能直接进入详情 |
| 媒体失败风险 | 有限衍生图回退，不重试已失败资源；统一保留尺寸的失败 / 重试状态；视频错误可恢复 | 用 synthetic fixture 验证图片全失败、慢响应、视频源失败、播放权限被拒；重试不会无限循环，alt 与 poster 保留 |
| 减少运动风险 | 各模块有清楚的静态替代与状态反馈，减少对全局 0.01ms 的依赖 | 减少运动下无强制自动换片，选择 / 暂停 / 完成状态明确；JS 平滑滚动尊重偏好 |
| token 与轻量动画 | 收敛功能字 / 面色 token；两处布局动画候选小范围改 transform | 不机械删掉旗子、历史轴、孕前边线；视觉层级与产品含义保持清楚 |
| 性能与影片 | 单独测冷 / 热访问和首帧，优先优化确认瓶颈；保存既有字幕事实与媒体版本 | 不凭一轮 LCP 定性；影片播放、暂停、seek、全屏 / 返回证据独立记录；听感与真机状态如实标注 |

建议 skill 顺序：`/impeccable harden` → `/impeccable animate` → `/impeccable optimize` → **`/impeccable polish`** → `/impeccable audit`。

## 发布整合与回归范围

实施前以当时最新 main 和已确认的生产 SHA 为基准，列出拟纳入的文件。当前共享工作树的删除和改动必须逐项确认与本方案的关系；不能通过 `git add -A` 将历史工作整包提交，也不能 reset、clean、stash 或覆盖无关改动。

生产仍有成长、人物、搜索和年书签跳转。建议这轮保持找回能力与旧链接；如要合并或删除，应先给出具体替代入口和重定向表，作为方案变更审批。微信媒体默认 private 保护需核对实际同步运行器与公开过滤，不以 Web SHA 代替流水线证明。

| 回归组 | 必须通过的行为 |
|---|---|
| 页面 | 五主栏目、开放辅助页面、旧书签 / redirect / 404、全部月份状态 |
| 阅读 | 搜索结果 / 无结果、年周日定位、日页返回、月报目录、地图到旅程 |
| 操作 | 焦点进入 / 循环 / 返回、Esc、浏览器返回、照片放大与合成触摸、视频播放 / seek / 全屏 |
| 可读性 | 功能字对比、320 / 390 / 768 / 1440px、200% 字号、单 main 与标题层级 |
| 数据与隐私 | 默认可见性、内部关闸、授权原件、年龄与日期、历史版本、fixture 录入与冲突 |
| 工程 | typecheck、Lint、有意义的相关测试、生产 build；通过后只提交 / push 本批文件 |
| 生产发布 | 另行人工批准；串行构建 / 切换 / 清理；报告当前 SHA、两版回滚、清理结果和磁盘空间 |

真机、微信 WebView、电视、读屏、主观听感不能用 Chromium 视口模拟替代。线上写入与生产切换需要具体授权，普通内容与代码检查由 Codex 完成。
